[requirement,model=ogc]
====
[%metadata]
identifier:: /req/resource-data-messages/content-negotiation/format-name

part::
When a protocol binding uses normalized *format names* to identify resource encodings within pub/sub channels, each format name SHALL be derived from the encoding's MIME type by applying the following normalization, in order:

1. Take the bare media type, discarding any parameters (everything from the first `;` character, if present, onward).
2. Remove the `application/` prefix, if present.
3. Replace every `+` character with a `-` character.
4. Lowercase all remaining characters.

part:: A protocol binding using this normalization convention SHALL define where the normalized format name is used in its channel addresses. This convention does not replace full media types used by a transport's content-negotiation mechanism. The substitution of `+` with `-` permits names to be used in MQTT topic segments, where `+` is reserved as a single-level wildcard.
====
