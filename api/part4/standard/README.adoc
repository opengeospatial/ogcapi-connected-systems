= OGC API - Connected Systems Part 4 Working Draft Status

This directory contains the current standalone working-draft entrypoint for
Part 4.

This branch-scoped package is designed to:

- preserve the existing upstream `api/part4` source material;
- provide a root draft entrypoint for a dedicated working branch;
- mirror the Part 3 working-draft packaging pattern without inventing missing
  standards content.

Currently included:

- `23-004r0.adoc` root draft entrypoint
- bounded front matter, scope, conformance, references, and terms wrapper
  clauses for the standalone working draft
- `sections/clause_3_references.adoc` standalone references clause integrated from Alex Robin's delivered package
- `build.sh` draft build helper
- `metanorma.yml` minimal Metanorma configuration

  `../sections/clause_13_sampling_feature_types.adoc`.
