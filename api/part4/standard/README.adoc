= OGC API - Connected Systems Part 4 Working Draft Status

This directory contains the current standalone working-draft entrypoint for
Part 4.

This branch-scoped package is designed to:

- preserve the existing upstream `api/part4` source material;
- provide a root draft entrypoint for a dedicated working branch;
- mirror the Part 3 working-draft packaging pattern without inventing missing
  standards content.

Currently included:

- `23-004r0.adoc` root draft entrypoint
- bounded front matter, scope, conformance, references, and terms wrapper
  clauses for the standalone working draft
- `sections/clause_3_references.adoc` standalone references clause integrated from Alex Robin's delivered package
- `sections/clause_13_sampling_feature_types.adoc` and its requirement files
  packaged beneath this standalone `standard/` directory
- `figures/` containing the PNG figures referenced by the sampling-feature-types
  clause and their corresponding SVG source assets
- `build.sh` draft build helper
- `metanorma.yml` minimal Metanorma configuration

Current wiring notes:

- The root entrypoint includes bounded standalone wrapper clauses ahead of the
  extracted sampling-feature-types clause.
- The root entrypoint includes
  `sections/clause_13_sampling_feature_types.adoc` from within the standalone
  package.
- The root entrypoint includes a standalone references clause before the
  extracted sampling-feature-types clause.
- The sampling-feature-types clause includes requirement files under
  `../requirements/sampling/`, which resolves inside the standalone package.
- Figure assets are stored under `standard/figures`, following the established
  Part 1 and Part 2 package convention. The existing `image::./figures/...`
  references therefore resolve when the committed root entrypoint is built
  directly.
- The `GeoPose` bibliography anchor was added in the standalone references
  clause because the existing Part 4 text explicitly cites it.

Known standalone-draft gaps intentionally left for later passes:

- the current front matter, scope, conformance, and terms clauses are bounded
  working-draft wrappers rather than fully promoted standalone Part 4 text
- bibliography extraction and reconciliation beyond the currently integrated
  references clause
- fuller standalone conformance packaging
- annex decisions
- broader Part 1 provenance cleanup

Open editorial questions intentionally left unresolved:

- `text for annex C.txt` was reviewed but not promoted into the formal draft in
  this branch because its annex status is still unclear.
- A direct `OGC-SML` bibliography entry is now included for the existing Part 4
  pose discussion, but the broader extracted-from-Part-1 requirement-class
  packaging remains unresolved.

Automated build path:

- GitHub Actions workflow `.github/workflows/part4-working-draft.yml`

Local helper:

`./build.sh`

The local helper remains a minimal convenience script. The GitHub Actions
workflow compiles the committed `23-004r0.adoc` entrypoint directly and
generates HTML, PDF, and XML review artifacts. It does not copy clauses or
requirements, create a temporary figure link, or rewrite the entrypoint before
compilation.

Artifact-handling note:

- the branch contains HTML and PDF review snapshots committed during its
  initial preparation;
- current automated builds upload HTML, PDF, XML, diagnostics, and the build
  log as commit-specific GitHub Actions artifacts;
- a future SWG decision should establish whether generated review artifacts
  remain committed or are retained only by CI and the OGC DRAFTS publication
  process.

- the root entrypoint resolves;
- the bounded wrapper clauses resolve;
- the included references clause resolves;
- the included sampling-feature-types clause resolves;
- the requirement include targets under `../requirements/sampling/` resolve;
- the figure assets resolve from the checked-in `standard/figures` directory;

  artifacts without a staged or rewritten document.

Reviewer-circulation status:

- this branch is suitable for reviewer circulation as a buildable working
  draft;
- it is not yet publication-ready and still carries explicit standalone-draft,
  requirements-packaging, and annex-disposition gaps that reviewers should read
  as open editorial issues rather than hidden build failures.

  the draft does not yet provide corresponding conformance classes/tests for
  the extracted requirement classes and still points to prerequisites outside
  this document;

  some inherited references, including `ISO 8601:2019`, `OGC/W3C`, and `IETF

- the current remote build still emits non-blocking rendering warnings,
  including a hanging paragraph warning and a duplicate `Layer_1` anchor from

- the current standalone wrapper clauses explicitly document, rather than fully
  resolve, missing promoted Part 4 source for submitters, scope, conformance,
  and terms treatment;
- annex treatment remains unresolved, including the status of
  `text for annex C.txt`;
- the current Part 4 draft still needs fuller requirements/conformance
  packaging around the historical `/req/sampling-features` base class;
- additional provenance and linkage cleanup remains needed before the branch
  should be treated as a fuller standalone draft package.
